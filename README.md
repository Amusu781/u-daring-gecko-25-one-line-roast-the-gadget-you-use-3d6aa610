# One-Line Roast: The Gadget You Use Every Day

A make.fun entry for
`u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`.

`main.py` writes a single original roast line (86 characters) to
`/output/entry.txt`:

> My microwave beeps five times when it's done, as if the first four were just practice.

## Run

```sh
python3 main.py
```

The program creates `/output` if needed, clears only its contents (never the
directory itself), and writes the one-line entry as UTF-8.
